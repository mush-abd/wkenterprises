## ⚙️ Content & Asset Management

All dynamic site content is isolated inside [`src/config/siteContent.ts`](file:///d:/Projects/WKEnterprises/src/config/siteContent.ts).

### 1. Product Item Schema
Each product card in `productsSection.items` accepts the following fields:
```ts
{
  id: string;                    // Unique identifier
  name: string;                  // Display title
  formulationCategory: string;   // Sub-label / category badge
  classification?: string;       // E.g. "Nutraceutical"
  packSize?: string;             // E.g. "60 Capsules • 1100 mg"
  badges?: string[];             // Pill tags (e.g. "Vegan", "Gluten Free", "97% Purity")
  description: string;           // Concise verified description
  amazonUrl?: string;            // When present, renders "Shop on Amazon" button; hidden when undefined
  imageUrl: string;              // Path to asset (e.g. "/products/berberine-hcl.jpg")
  altText: string;               // Accessible alt description
  isPlaceholder?: boolean;       // False for confirmed items
}
```
